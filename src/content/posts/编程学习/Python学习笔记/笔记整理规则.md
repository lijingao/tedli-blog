# 笔记整理规则

## 基本原则
- **内容准确性第一**：整理图片笔记前，必须先学习确认真实的知识点，不能直接照搬图片内容
- **如有疑问，查证后再写**：不确定的知识点要先确认，宁可多花时间也要保证准确

## 笔记结构
- Frontmatter：title、published、tags、description
- 正文内容：概念解释 + 代码示例
- 不包含练习题（用户自己添加）

## 命名规则
- 根据笔记内容提取关键词命名
- 使用中文命名
- 格式：`知识点名称.md`

## 存放位置
- 由用户指定，当前为：`content/posts/编程学习/Python学习笔记/`

## 格式规范
- 代码块使用 ```python 标记
- 表格使用标准 Markdown 表格格式
- 重要知识点加粗或使用引用块
- 每篇笔记控制在合理篇幅，不堆砌内容

## 图片处理
- 只提取文字信息，不保存图片
- 如需图片说明，使用文字描述或代码示例替代
